# Contributing

## Branch
Gunakan branch terpisah untuk setiap tugas atau perubahan.

## Commit
Gunakan format:
<tipe>(<bagian>): <ringkasan perubahan>

Contoh:
feat(pertemuan-2-tugas-mandiri-1): tambah hasil pengujian HTTP

## Pull Request
Setiap tugas dikirim melalui Pull Request ke main dan direview sebelum merge.

## Issue
Catat kendala pengerjaan melalui GitHub Issue jika diperlukan.

Jangan commit password, token, file .env asli, atau folder dependency.
